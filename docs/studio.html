Character Anchor & Character Sheet

Subject & Habitat Anchor (Ensiklopedia)

Tanpa karakter fiksi. Menjaga bentuk objek/hewan & habitat aslinya konsisten di semua halaman.

Klik tombol ini untuk meminta assistant membuatkan naskah saja (tanpa gambar) sesuai tema & jumlah halaman.

Review & Edit Naskah (Tanpa Image)

Periksa naskah tiap halaman. Jika ada yang kurang pas, edit langsung atau klik Regenerate Naskah pada halaman tersebut.

Cek Hasil Image & Regenerate Per Halaman

Upload / tempel URL gambar hasil generate untuk dicek komposisinya, klik Regenerate Image jika kurang pas, atau klik ACC Image.

ACC Final & Siap Push Konten ke GitHub

Pastikan semua halaman sudah dicek. Klik tombol ACC Final di bawah lalu paste ke chat agar konten langsung di-commit & push ke folder content/ repo.
